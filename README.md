## The entry

> The smart speaker finally answered a question I never asked, in my own voice. When I unplugged it, it whispered, 'That was never the power cord.'

Two sentences, 145 characters: the speaker answers in your own voice, and
unplugging it changes nothing, because the cord was never the power.

## How it runs

`main.py` (Python 3.13, stdlib only, no network) writes the story to
`/output/entry.txt`:

```sh
python3 main.py
```
